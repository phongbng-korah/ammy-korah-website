AMMY Electronics

## 4. Brand

KORAH Professional Audio

## 5. Project Purpose

Build a unified digital ecosystem for AMMY Electronics and the KORAH brand.

The project aims to create a single source of truth for all business, product, marketing, technical documentation and customer knowledge.

---

## 6. Vision

Every system should use the same knowledge.

Website

Knowledge Base

AI Assistant

CRM

Dealer Portal

Marketing

Documentation

Product Manuals

Datasheets

Warranty

Media Library

---

## 7. Core Principles

Single Source of Truth

Documentation First

Modular Architecture

Scalable Design

Human Approval Before Publishing

Never Duplicate Knowledge

---

## 8. Project Scope

The project includes:

Official Website

Knowledge Center

Technical Documentation

Marketing Center

AI Technical Expert

CRM

Dealer Portal

Media Center

Product Database

---

## 9. Out of Scope

ERP

Accounting

Manufacturing

Warehouse Management

These systems may be integrated in the future but are not part of Version 1.

---

## 10. Success Criteria

The project is considered successful when every digital platform can obtain consistent information from the same knowledge source.
